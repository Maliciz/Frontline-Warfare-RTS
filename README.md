## 🪖 Особливості та ігрова механіка

- **Військова тактика та будівництво бази:**
  - **Командний пункт (Headquarters / Штаб):** Серце вашої оборони. Забезпечує базовий приріст припасів, радарну розвідку та відкриває технології.
  - **Казарми піхоти:** Навчання стрільців (захоплюють ресурсні вишки) та штурмовиків РПГ (протитанкові розрахунки).
  - **Завод бронетехніки:** Серійне виробництво БМП «Буцефал», Танків Т-84 «Оплот», САУ «Богдана» та комплексів ЗРК ППО.
  - **Станція БПЛА:** Виробництво та бойове застосування надшвидких ударних FPV-дронів камікадзе.
  - **Склади постачання:** Розширення ліміту армії (+15 одиниць) та забезпечення безперебійної логістики.
  - **Оборонні укріплення:** Кулеметні ДОТи проти піхоти та Ракетні бастіони проти важкої ворожої техніки.

- **Карткова система та ресурси:**
  - **Стратегічні ресурсні вишки (Supply Derricks):** Нейтральні нафтові свердловини на ключових перехрестях та мостах. Захоплюються піхотою та приносять +20 припасів кожні 3 секунди.
  - **Тактичний ландшафт:** Асфальтовані магістралі (+25% швидкості для техніки), лісопосадки (+30% оборонного укриття для піхоти від ворожого вогню), водні перешкоди (річки) та мости-плацдарми.

- **Бойовий баланс (Rock-Paper-Scissors):**
  - 💥 **FPV-дрони камікадзе** на надзвуковій швидкості проривають оборону і влучають у важкі танки та артилерію.
  - 🎯 **ЗРК ППО та БМП** збивають ворожі FPV-дрони на підльоті чергами зенітних автопушок.
  - 💣 **Танки Т-84 «Оплот» та САУ** на відстані розносять ворожі ДОТи, заводи техніки та бази.
  - 🌲 **Штурмовики РПГ** влаштовують засідки в лісах проти ворожих танкових колон.

- **Туман війни (Fog of War):**
  - Повноцінна 3-рівнева система видимості: *Нерозвідано (темрява)*, *Розвідано (затінений туман із відомим ландшафтом)*, *Пряма видимість (повний тактичний огляд)*.

- **Бойовий штучний інтелект (AI):**
  - 3 рівні складності: **Рекрут (Легко)**, **Сержант (Нормально)**, **Ветеран / Комбат (Важко)**.
  - Комп'ютерний супротивник самостійно будує базу, захоплює стратегічні нафтові вишки, комбінує роди військ, завдає точкових ударів FPV-дронами та контратакує при загрозі своєму командному пункту.

- **100% Автономний процедурний звук:**
  - Реалістичні звуки танкових залпів, свисту і розривів артилерійських снарядів, гуркоту гусениць, дзижчання FPV-дронів, радіокоманд та сирен тривоги синтезуються математично через `NumPy` в пам'яті гри без залежності від зовнішніх аудіофайлів!

- **Оптимізація під гру без світла:**
  - Режим енергозбереження батареї (**ECO 30 FPS / 60 FPS**, клавіша `F`), що мінімізує енергоспоживання процесора та відеокарти при роботі від акумулятора.

## 🕹️ Керування та гарячі клавіші

| Клавіша / Дія | Призначення |
| :--- | :--- |
| **ЛКМ (Ліва кнопка миші)** | Вибір юніта / будівлі; натискання та перетягування — виділення армії зеленою рамкою |
| **ПКМ (Права кнопка миші)** | Наказ руху / атаки по цілі / захоплення ресурсної вишки |
| **WASD** або **Стрілки** | Переміщення камери по полю бою |
| **Клік по Міні-карті** | Миттєвий перехід камери в обрану точку карти |
| **Ctrl + 1..9** | Створення бойової групи / загону |
| **1..9** | Швидкий вибір створеного загону |
| **A** | Наказ «Атака через рух» (Attack-Move) |
| **S** | Наказ «Стоп» (зупинити всі дії) |
| **H** | Перемістити камеру на Командний пункт (HQ) |
| **Space (Пробіл)** | Перехід до місця останнього бою або тривоги |
| **F** | Перемикання режиму економії батареї (30 FPS / 60 FPS) |
| **M** | Увімкнути / вимкнути звук |
| **Esc** | Меню тактичної паузи |

## 🚀 Запуск гри

### Варіант 1: Запуск готового `.exe` (Рекомендовано)
Запустіть `FrontlineWarfare.exe` (знаходиться на Робочому столі або в репозиторії). Гра запуститься миттєво без потреби встановлювати Python.

### Варіант 2: Запуск із вихідного коду
```bash
git clone https://github.com/Maliciz/Frontline-Warfare-RTS.git
cd Frontline-Warfare-RTS
pip install pygame-ce numpy
python main.py
```

## 🛠️ Збірка в один файл `.exe`

Для створення автономного виконуваного файлу для Windows використовується скрипт збірки:
```bash
python build_exe.py
```
Готовий автономний файл `FrontlineWarfare.exe` генерується в кореневій папці проекту.
